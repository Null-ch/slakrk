# Моё похудение

Мобильное приложение для дневника питания и активности. На первом этапе доступны главная со стартовыми показателями и экран «Ещё» со стартовым профилем. План работ и открытые вопросы описаны в [PLAN.md](PLAN.md).

## Локальный запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Для проверки типов и production-сборки выполните `npm run build`. Команда `npm run preview` позволяет открыть собранное приложение.

## Docker

```sh
docker compose up --build -d
```

Откройте [главную](http://localhost:8080/) и [экран «Ещё»](http://localhost:8080/more). Прямая ссылка на второй экран проверяет маршрутизацию Nginx. Порт можно задать переменной `APP_PORT`. Compose публикует его только на loopback, поэтому для доступа через домен нужен HTTPS-прокси на хосте.
