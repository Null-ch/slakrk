# Моё похудение

Личные кабинеты, дневник веса и питания, тренировки А/Б, ходьба, покупки и календарь. Новый профиль строит примерный 21-дневный план после ввода веса, роста, возраста и пола.

## Запуск в Docker

```sh
docker compose up --build -d
```

Откройте [приложение](http://localhost:18080/). Сборка проверяет типы клиента и сервера. Регистрация доступна на экране входа. Аккаунты и серверные сессии хранятся в SQLite на постоянном Docker-томе `accounts`.

## Дневники и план

- Для каждой учётной записи создаётся отдельная база IndexedDB в текущем браузере. Записи между устройствами переносятся через JSON из раздела «Ещё». Там же можно сменить пароль.
- При обновлении прежняя локальная база сохраняется. Для переноса записей в личный кабинет используйте ранее выгруженную копию JSON. Приложение предлагает импорт при первом входе.
- Офлайн можно продолжить в уже открывавшем кабинет браузерном табе. Для регистрации, первого входа и выхода нужен сервер.
- Калорийность рассчитывается приблизительно по формуле Миффлина — Сан Жеора для сидячего режима. Четыре поля подходят для оценки энергии. Для нагрузки используется стартовый календарь А/Б и ходьба в комфортном темпе.
- Пищевые оценки основаны на приблизительных справочных данных [USDA FoodData Central](https://fdc.nal.usda.gov/). Экран питания показывает цель, меню на день и отметки о порциях.
- Напоминания работают в открытом приложении. Файл ICS можно открыть в системном календаре.

## Развёртывание

`deploy/install.sh` настраивает выделенный HTTPS-хост `stop-jir.gncp.work` на существующем Nginx и публикует контейнер через loopback. Nginx передаёт доверенные заголовки протокола и IP. Сервер выпускает cookies HttpOnly и SameSite, а через HTTPS также Secure. При переносе на другой сервер сохраните Docker-том с SQLite и JSON-копии дневников.

Для создания предзаданных пользователей передайте массив записей с полями `name` и `password` через stdin команды `docker compose exec -T app node --experimental-strip-types server/seed.mts`. Файл с паролями должен находиться вне репозитория. При повторном развёртывании без новых аккаунтов эта команда не нужна.
