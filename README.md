# Моё похудение

Личный дневник питания, веса, силовых тренировок и ходьбы. Мобильный интерфейс, 21-дневная программа, покупки, графики и перенос данных через резервную копию.

## Запуск в Docker

```sh
docker compose up --build -d
```

Откройте [приложение](http://localhost:18080/). При сборке образа запускаются проверка TypeScript и production-сборка Vite. Compose публикует порт только на loopback. Порт можно переопределить через `APP_PORT`.

## Питание и хранение

- Базовое меню хранит исходные блюда и порции. В редакторе меню можно поменять продукты и граммы на выбранный день. Список покупок учитывает изменения.
- Для части продуктов есть приблизительные значения [USDA FoodData Central](https://fdc.nal.usda.gov/). Для остальных укажите массу и пищевую ценность с упаковки. Сумма меню помечена как неполная, пока не уточнены все позиции.
- Данные лежат в IndexedDB конкретного браузера и домена. Для перехода с localhost или другого устройства экспортируйте JSON в разделе «Ещё», затем импортируйте его на новом адресе.
- PWA устанавливается через меню браузера после входа и первой загрузки. После подготовки кеша уже открывавший приложение браузер может использовать его офлайн.
- Напоминания в приложении требуют открытой страницы. Файл ICS можно открыть в системном календаре.

## Развёртывание

`deploy/install.sh` предназначен для выделенного виртуального хоста `stop-jir.gncp.work` на существующем Nginx. Он использует выпущенный сертификат Let’s Encrypt, собирает Docker-образ, публикует его на loopback и защищает HTTPS одним пользователем `owner` через HTTP Basic. Пароль задаётся при первом развёртывании вне Git. Для следующего развёртывания используйте действующий пароль. Без HTTPS логин и пароль передавать нельзя.

Вход защищает доступ через сервер. Браузерный профиль и уже сохранённые локальные записи защищаются блокировкой устройства. Между браузерами доступен ручной перенос через JSON.
